# KK_Quick_Attribute_Jump

QGISのレイヤから属性値を選び、その値を持つ地物を属性テーブルで確認して地図上の位置へ移動するプラグインです。

- 作成者: kouichi kita
- 対応QGIS: 3.40～4.99
- 表示場所: QGIS右側のプラグインパネル


## 基本的な使い方

1. 「レイヤ設定」を開き、「検索するレイヤ」で対象のベクタレイヤを選びます。
2. 「検索する属性」でカテゴリ分けに使うフィールドを選びます。
3. 必要に応じて「レイヤ設定保存」をクリックします。
4. 「場所を探す」をクリックし、表示されたカテゴリボタンから値を選びます。
5. 選んだ値で絞り込まれた属性テーブルがQGIS下部のパネルに表示されます。
6. 属性テーブルの行を選択すると、対応する地物の位置へ地図が移動します。

カテゴリの値は重複をまとめてボタン表示します。NULL値は「(NULL)」として表示されます。別のカテゴリを選ぶと、表示中の属性テーブルパネルが新しいカテゴリの内容に切り替わります。

## パネルとボタン

### プラグインパネル

| 項目 | 機能 |
|---|---|
| 場所を探す | 選択中のレイヤ・属性に含まれる値をカテゴリボタンとして表示します。 |
| レイヤ設定 | 検索対象のレイヤと属性を選択します。クリックすると現在のレイヤパネルにある有効なベクタレイヤから選べます。 |
| レイヤ設定保存 | 選択中のレイヤと属性を、プロジェクトごとの設定ファイルに保存します。 |
| 表示設定 | パネルの自動表示、ボタン・属性テーブルの表示方法を設定します。 |
| 表示設定保存 | 表示設定をプラグインフォルダの設定ファイルに保存します。 |

「レイヤ設定」と「表示設定」は、見出しをクリックすると開閉できます。

### カテゴリダイアログ

各ボタンは、検索属性に含まれる異なる値を表します。値をクリックするとカテゴリダイアログが閉じ、その値を持つ地物だけを含む属性テーブルが表示されます。

### 属性テーブルパネル

| ボタン・操作 | 機能 |
|---|---|
| 閉じる | 属性テーブルパネルを閉じます。 |
| 列幅を調整 | フィールド名と属性値の内容に合わせて列幅を調整します。 |
| 行を選択 | 対応する地物の位置へ地図を移動します。 |

列幅はカテゴリを切り替えても自動変更されません。必要な場合に「列幅を調整」をクリックしてください。

## 表示設定

| 設定 | 機能 |
|---|---|
| 常に表示する | 有効にして表示設定を保存すると、次回QGIS起動時にプラグインパネルを表示します。 |
| ボタンの文字サイズ | 「場所を探す」とカテゴリボタンの文字サイズを指定します。ボタンの高さも文字サイズに応じて変わります。初期値は20です。 |
| 属性テーブルの行の高さ | 属性テーブルの各行の高さを指定します。初期値は20です。 |
| 属性テーブルの文字の大きさ | 属性テーブルのセルとフィールド名の文字サイズを指定します。初期値は12です。 |
| 地物にズームするとき縮尺を変えない | 有効時は現在の縮尺を保ち、選択した地物の位置へパンします。無効時は地物の範囲に合わせて縮尺を調整します。 |

数値の入力範囲は、ボタン文字サイズと属性テーブル文字サイズが6～72、行の高さが8～100です。パネルに属性テーブルが表示されている場合、行の高さ・文字サイズ・縮尺維持の変更はテーブルへすぐ反映されます。ボタン文字サイズもカテゴリダイアログのボタンに反映されます。

## 設定ファイル

### レイヤ設定

「レイヤ設定保存」で、現在のQGISプロジェクトと同じフォルダに次のファイルを作成または上書きします。

`KK_Quick_Attribute_Jump_Setting.json`

保存されるのは検索対象のレイヤと属性です。プロジェクトを開いたとき、このファイルがあれば設定を読み込みます。レイヤ設定を保存する前に、プロジェクトを保存してください。

### 表示設定

「表示設定保存」で、プラグイン本体と同じフォルダに次のファイルを作成または上書きします。

`Setting.json`

「常に表示する」、ボタンの文字サイズ、属性テーブルの行の高さ・文字サイズ、縮尺維持の設定を保存します。QGIS起動時に読み込まれ、「常に表示する」が有効ならプラグインパネルが表示されます。

## 注意事項

- 検索対象には有効なベクタレイヤを選択してください。
- 属性テーブルの行選択による地図移動は、地物がジオメトリを持つ場合に行われます。
- 設定ファイルを保存するには、プロジェクトフォルダおよびプラグインフォルダへの書き込み権限が必要です。
